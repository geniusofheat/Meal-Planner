Full Version Tools :

Tap a tool name to see its features. Click the open button to open the tool.

  1. 📋 Grocery List :

    Open !

    Features :

    1. Smart Add Tool : +

      Build your grocery list by typing an item name into the text box or speaking into the microphone(🎤) and pressing the add(+) button.

    2. Smart Lock : 🔒

      When shopping, check the items you purchase. Press the lock button to lock your selections.

    3. Grocery Menu :

      Browse a directory of grocery items within a smart menu to select multiple items without typing.

    4. Grocery Menu Smart Search :

      Search the grocery menu with the text box by typing a name or by speaking into the microphone(🎤).

    5. Save Grocery List :

      You can pin the grocery list to the meal planner for future reference. This allows you to plan a grocery trip for a specific day.

  2. 📖 Cookbook :

    Open !

    Features :

    1. Recipe Cards :

      You have access to hundreds of chef-inspired recipes sorted and alphabetized into categories. Each recipe card opens in its own popup window so you can keep your place in the menu.

    2. Favorite Recipes :

      Add recipes to your favorites list by pressing the star button.

    3. Meal Planner Access :

      Use recipes with the meal planner. Press the plan button within each recipe card.

    4. Recipe Creator :

      Recipe creator lets you create a recipe card with the same cookbook recipe layout. Accessible only in the cookbook.

    5. Recipe Finder :

      The smart search tool lets you search recipes by name or ingredients. Use the text box or the microphone to search the cookbook.

  3. 🔎 Recipe Finder :

    Open !

    Features :

    1. Smart Search :

      Type into the text box or speak into the microphone(🎤) to search by recipe name or ingredient.

    2. Full Cookbook Scan :

      Every category in the cookbook is searched at once, so you never have to hunt through categories one by one.

    3. Highlighted Matches :

      Matching recipes are highlighted directly in the menu so you can jump straight to what you're looking for.

  4. ♡ Favorites List :

    Open !

    Features :

    1. Save With One Tap :

      Press the star button on any recipe in the cookbook to add it straight to your favorites list.

    2. Quick Access :

      All of your saved recipes live together in one place, no digging through categories.

    3. Meal Planner Ready :

      Favorite recipes can be added directly to the meal planner calendar.

  5. 📅 Meal Planner :

    Open !

    Features :

    1. Monthly Calendar :

      Plan a different meal for every day of the month, laid out in a simple calendar view.

    2. Cookbook Integration :

      Choose recipes straight from the cookbook or your favorites list to fill in any day.

    3. Custom Recipes :

      Create your own recipe cards and use them in the plan right alongside cookbook recipes.
